01 / Background

Why sensor data quality matters

Environmental monitoring is useful only when measurements are sufficiently complete and reliable. Our project studied quality issues across rainfall, river discharge and river water-level records, then examined suspicious rainfall periods in greater depth.

01 / DATA

Three sensor types

113 rainfall files, 53 river-discharge files and 55 water-level files formed the source collection.

02 / QUALITY

Statistical screening

We investigated missing values, repeated station–sensor–timestamp groups and unusually high observations requiring review.

03 / FOCUS

Four rainfall stations

Neighbour comparison and station selection supported the focused machine-learning experiment.

02 / Research workflow

From raw readings to interpretable evidence

An offline analytical workflow developed in Python and Google Colab. Saved results were integrated into the Streamlit dashboard.

1. Ingest CSV data221 files + station inventory
2. StandardiseStation, timestamp, type, value, unit
3. InvestigateEDA, long zero runs, neighbouring gauges
4. Evaluate MLSix models, synthetic faults
5. VisualiseInteractive Streamlit dashboard
Research limitation: This is a retrospective prototype, not a live monitoring or early-warning service. Unusual readings and model alerts do not establish confirmed sensor faults.
